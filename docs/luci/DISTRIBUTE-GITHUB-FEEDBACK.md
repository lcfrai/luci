# GitHub feedback in Distribute

This source adds an explicit preview → select/share → import workflow for the project's current attached github.com origin. It uses the existing workspace GitHub CLI authentication, which is not proof of the current Luci person's GitHub identity. The native boundary pins the absolute executable's ordinary one-name file identity/bytes/SHA before and after a single fixed GET. It does not attest an atomic handle-based executable launch.

One page of at most 100 GitHub rows is requested using the retained 2022-11-28 API version. Pull requests are excluded. Issue bodies are bounded excerpts, and both provider and later model-context omissions are reported. Output overflow refuses the preview; no partial result is imported. The command is not paginated, retried or inferred from prose.

Preview/import/selection require current project Read, Edit and Secrets. Grants are freshly resolved after waiting I/O. A preview is private to its original actor/team/project and exact source context for ten minutes. A user must choose exact issue versions and acknowledge sharing them with project readers. Imported records preserve repository, number, provider updatedAt, content digest, attribution and source context; they are reports, not verified demand. Exact retained import retries are idempotent. The latest 200 observations are retained, protecting the current discussion selection; old unselected records and their retry receipts may be pruned. This is bounded retained history, not a permanent archive.

“Review findings with Luci” explicitly saves selected existing observations and opens the existing unsent Luci composer. It does not submit a model request, replace an unsent message or apply a proposal. The normal model/Execute/Secrets/policy/cost checks still govern sending. The exact optional captured context is untrusted historical evidence. It contains short plain-text excerpts with source IDs/digests and explicit omission counts, never instructions or permission to follow links. No selected feedback means no new legacy JSON field or digest layer. Roadmap/GTM changes remain proposals behind existing explicit review/apply gates.

No arbitrary repository, URL, executable, token or CLI arguments come from a request. No comments, PRs, follow-up network reads, publication, outreach, acquisition or new provider loop are added. UI source uses existing project scopes, draft/navigation guards, shared controls and tokens. Root-owned Distribute hierarchy integration is supplied as two contextual edits only. Source tests are authored but have not been run in this source-only pass.
