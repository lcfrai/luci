## Included implementation

The preceding 0.4.17 batch added shared per-account model connections across
guided Define, repository analysis and Develop; configurable LiteLLM access;
preserved model selection; Docker-specific Codex Ask compatibility; and private
persistent Shell homes. Explicit incompatible/disabled connections fail without
switching billing accounts. Shell receives no model credentials. Actual pinned
CLI fixtures produced files and served HTTP using deterministic provider
responses, rather than a live subscription or gateway.

The current 0.4.18 batch adds:

- **Private review authority:** authenticated controller-owned receipts outside
  coding mounts bind account/project, full brief/specification/sketch/design
  content and the latest selection. Save revokes affected approvals. Imported
  or legacy content stays readable but needs fresh review. Native/local/cloud/
  Pages application deployments require current reviews and matching committed
  context exports.
- **Reviewed task handoff:** sessions retain server-resolved task identities,
  linked requirements, saved plan/review revisions and immutable starting source.
  Restart/resume refuses stale/foreign inputs before replacement or allocation.
  The history records inputs, not verified task completion.
- **Preview ownership and health:** HTTP/WebSocket forwarding checks the actual
  running container, ownership and exact loopback binding. Dead/foreign/rebound
  containers receive no traffic. Interrupted builds become unknown; ready rows
  require bounded fresh health checks. Observation never replays operations.
- **Workspace and Design recovery:** shared connections follow the selected
  remote execution workspace; optional prototype-history failure no longer
  blocks the saved Design handoff and approval controls.
- **Packaging and CI:** successful Windows builds remove only their validated
  generated stage; failed stages remain. CI records actual required test success
  before artifact upload, allowing native/portable tests to proceed when upload
  quota fails. Upload failures remain failures.
