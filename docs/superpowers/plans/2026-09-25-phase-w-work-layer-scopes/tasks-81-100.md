  `feat/hub`** (rule H1); sibling-plan paths (Phase T) are **UNVERIFIED until merge** (rule H2).
- "05 §x" is `docs/superpowers/planning/2026-09-25-linear-parity/05-design.md` (revision 2);
  "L-n" is row n of the parity matrix in `01-linear-feature-inventory.md` as 05 §1 prices it. A
  row a task **closes** is built there and counts only when the task's acceptance commands pass;
  a row it only **serves** names the task that closes it; a row closed jointly names every task.
- Seams are the skeleton's `SW.n` (*Seams* table). `SW.18` is the W2 wire (`WorkPlan`, task 72);
  `SW.19` is the W3 records (task 99). Every surface test calls `expectNoPrediction(container)`

  `-tags integration` against `control-plane/cmd/hub/compose.yaml`; desktop tests as
  `npm --prefix desktop test` and `npm --prefix desktop run typecheck`.
