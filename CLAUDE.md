# Luci contributor context

Read `AGENTS.md` and `docs/luci/PLAN.md` first. Luci is an open-source lcfr.ai product, built independently of KPMG. The current user-approved scope supersedes historical Panacea plans, corporate integration assumptions, phase restrictions and repeated review gates.

Keep Define, Design, Develop and Deploy connected through one project, its versioned brief, design and release evidence. Prefer local operation and single-machine deployment. Use Glasses to discover reusable open-source components and verify their licences before adopting them.

Work autonomously within the requested scope. Plan interfaces before parallel implementation; run meaningful tests and complete user journeys. Do not treat old task-specific review mandates as current approval requirements.

Creating billable cloud resources or publishing a release requires actual credentials and a concrete accepted target. Product setup must show costs and a cleanup path before creation. Never import private corporate code, credentials or endpoints into an open-source release.
