## Implemented boundary

The backend pins a complete trusted spec: source commit/digest, closed finite
manifest, helper binary, fixed recipe/base config, actor/scope/allocation and
command digest. Missing inputs, changed pins, unavailable selected local SDK,
unsupported resource limits or a different backend refuse. Prepare allocates
no container. No default engine, environment transport, image pull/build/load,
Docker socket, URL, arbitrary argv, agent/check/parser cross-adoption or fallback
exists. The optional coordinator has no registered caller/route/autostart.

Container resources remain readonly root,2GiB memory=total swap,1CPU/64PIDs,
network/IPCnone,2GiB `/work` tmpfs and128MiB `/tmp`. UID0 receives only CHOWN,
DAC_OVERRIDE,FOWNER,FSETID,SETUID,SETGID,SYS_CHROOT,MKNOD. No SYS_ADMIN, proc mount,
host devices, writable project path or unconfined seccomp. MKNOD is used solely
for the exact retained temporary chroot dev/null1:3. All package children remain
inside this same resource domain; their scripts are genuinely executed.

Readonly binds alone do not pin host bytes. Before Create, the Windows adapter
opens every finite input/helper/directory with READ sharing only, refusing
reparse/hardlink substitutions and retaining handles through uncertain outcomes.
It rechecks pinned bytes before Create/Start; the helper independently copies and
hashes the finite inputs into owned tmpfs before executing any package. Other
host platforms refuse this optional profile before daemon effects because an
advisory file lock cannot supply the same guarantee. Source/read-handle Close
failure retains ownership. No change to the existing parser/check semantics.

Attach preserves the selected local SDK endpoint, negotiated version and explicit
trusted headers. It refuses opaque/TLS/fallback transports. The actual hijack
connection gets a deadline before handshake; native connection ownership is
registered before dialing and failed closes remain reachable. Startup requires
the exact acknowledged created CID and its owned pre-Start stream. Raw Docker
headers/frames have independent total/count/size limits; foreign, zero, extra or
truncated frames refuse. The collector writes in64KiB chunks into an exclusively
owned2GiB-bounded host artifact, never a giant byte slice. Close ACK errors are
explicit. Complete framing/hash, observed exit0/non-OOM, exact retirement,
reader/sink settlement and durable publication are separate facts.

The private lifecycle uses one300s compute/120s cleanup/420s absolute attempt.
Fresh current installation authority/source and8GiB headroom precede Create and
Start. During work4GiB/unknown headroom invokes exact retirement before any blocked
reader/publisher. Uncertain Create/Start requires durable fence intent, actual
marker Create ACK and verification; later readback is not an ACK. Expiry never
settles a lease. Recovery only retires/fences; it cannot attach late/start/replay or
claim missing capture. A reader still blocked after the deadline retains the
exact lifecycle lock until it settles/process death and leaves capacity held.

The helper is a standalone Go standard-library module. A source regression binds
its pure manifest/profile validator mirror to the authoritative backend source.
It self-verifies its pinned static ELF, closure flags and dependency lock state;
the unresolved current lock refuses before native package execution. It checks
actual cgroupv2 memory/swap/CPU/PID values, fixed effective/permitted/bounding
capabilities, no-new-privileges/seccomp and mount/tmpfs bounds before creating its
workspace. Unknown writable disk mounts refuse. Moby's known default kernel-file
null masks require exact tmpfs/null binding plus character-device1:3 stat; they
are not permission for another writable host file. No host/inner proc mounting.

The base reader bounds expansion1GiB,100,000 members,128MiB member and1MiB PAX,
checks single gzip framing and exact uncompressed OCI diff_id, and rejects special
devices/unsupported dialects/whiteouts/traversal/duplicate paths. Virtual-root
resolution interprets absolute symlinks inside the chroot. The fixed dpkg
unpack/configure and pip no-index/no-deps/binary/hash recipe has no network
resolver or skipped maintainer script. Native verification uses the already
pinned dedicated verifier. Persisting package children, unexpected transient
replacements or another device refuse export. The temporary dev/null and install
directory are removed only after their retained identities match.

Export canonicalizes timestamps, preserves actual file modes/owners, bounds the
complete rootfs/layer and finite path inventory, and emits config/manifest/index
with fixed nonroot parser USER/ENV/ENTRYPOINT and exact source/retention labels.
Two passes compute and check tar length/hash without another large OCI archive
staging file. Rootfs, staged inputs and compressed layer still compete for the
same2GiB tmpfs/cgroup. No successful install/build within this cap is promised.
The flattened OCI is a new recipe, not classic Dockerfile byte equivalence.
