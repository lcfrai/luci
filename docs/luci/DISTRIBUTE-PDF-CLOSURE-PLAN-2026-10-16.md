## Fixed shaping/subset interface to prove before production export

The pilot consumes the exact saved artifact bytes and pinned font manifest. It segments original Unicode into clusters, shapes each run with script/direction/language and the selected face, and records every shaped glyph's original cluster, face index, glyph ID, advance and offset. Assign a distinct bounded PDF CID for each `(face, glyph ID, original Unicode cluster)` mapping; repeated glyph IDs with different clusters **must not** share a ToUnicode mapping. Refuse more than 65,535 CIDs. Group glyph IDs by face, call pinned `SFNT.Subset(glyphIDs, KeepPDFTables)`, then map requested old glyph IDs to the returned order and account for appended composite dependencies before writing the appropriate TrueType CIDToGIDMap or CFF program/embedded streams. A CFF2 face refuses. Generate ToUnicode from original clusters, not from a reverse glyph lookup. Measure line breaks using shaped advances and preserve original logical text order in extraction; a visibly correct page with reordered or missing extracted text fails.

The pilot must prove exact round-trip extraction and page layout for Latin ligatures, Arabic joining/RTL, combining marks, CJK, table wraps, multi-page source references and unsupported-glyph refusal. It must show selected CJK TTC face subsetting as a standalone font rather than embedding the 19 MiB collection. Missing glyph/script, invalid cluster map, oversized subset, clipped row, cancellation or any unknown writer behavior returns an explicit refusal; there is no raster fallback or silent glyph replacement.

A failure stops this candidate; it does not silently select another font. Only after that gate, add TrueType Latin/Arabic and mixed-script pages. Charge at least 512 MiB shared host admission, hold `ExecutionStateDir/distribute-work.lock` across managed API workers, cap input font bytes at 32 MiB, intermediate at 32 MiB, final PDF at 16 MiB, artifact at 256 KiB, pages at 512 and whole request at 30 seconds. Check cancellation in shape/subset/layout/write and retain no success on cancel. No external renderer process or remote service.
3. Compare independent text extraction with each original cluster and visually inspect page breaks/tables on the supported desktop. Record peak host/cgroup memory, elapsed time, retained allocations and positive cleanup. Only then choose production integration and release-package/licence closure. This pilot does not establish installed Windows/Office fidelity, model quality, public delivery or full LC21 acceptance.
