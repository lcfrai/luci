The wrapper forwards Write unchanged, so this alone does not alter frame bits or split data. All underlying reads/writes/close reach the same transport. ## Interpretation of relay status1000

The relay ignores the error returned by dst.Close, then sends/returns the source Read error. The installed Info log's status1000 therefore proves only a retained normal-close error, not successful transmission of a close frame to Chromium. If v8's privately retained exact browser error is inconclusive, a separate explicit diagnostic overlay recording relay direction and Close-result class/hash would be stronger evidence than another unchanged ordinary test. Such an overlay must be identified as diagnostic and cannot silently replace the accepted runtime.
