**The data rule, stated because Slack is outside the Microsoft tenancy:** inbound, a message
becomes a request's verbatim quote as `text·H` of its author (§3.5 step 2, task 146's `rq-`);
outbound, **nothing leaves as customer text**. A feed item, an unfurl and the digest carry
SW.22's metadata (ids, changed fields, actor) plus the display alias, the state's word and an
https link to task 80's read-only issue page, which Entra protects; never a title, body, quote
or comment. The Desk digest (task 165's content rule) goes as a Slack DM to a linked person and
carries each Desk section's **measured count** and a link, no titles (`OD-27`: counts, no
prediction). **The notification budget is per person, across providers**: one digest per 15
minutes whether it goes by Teams, Slack or mail (`docs/AGENTIC-UX.md:243`, anti-pattern 8).
Slack's interactive actions are *Open* and *Subscribe* only, as the linked person; there is no
state, assign or priority action, and no act from Slack writes a fact state or `done` (SW.3).
Slack's own request check, as its public docs describe it (**UNVERIFIED here**, since slack.com
may be blocked on the corporate network): `X-Slack-Signature: v0=<hex HMAC-SHA256(signing
secret, "v0:" + X-Slack-Request-Timestamp + ":" + raw body)>`, compared in constant time, the
timestamp within 5 minutes; Slack's retries are deduplicated by `event_id`. **Tests first:**
a wrong signature is 401 and writes nothing (kills an unchecked signature); a valid signature
with a timestamp 6 minutes old is 401 (kills a replay window); a message shortcut makes one
`rq-` whose quote equals the message text byte for byte and lands in the rule-routed team's
`triage` (kills rewritten text and a request that skips intake rules, task 147); a retried
event with the same `event_id` adds no second comment (kills a double sync); a thread reply
arrives as a comment on the request, attributed to its Slack author (kills an unsynced thread);
a seeded title `ZZ-TITLE-CANARY` appears in no outbound Slack body, feed, unfurl or digest (kills
a text leak); an unlinked Slack user pressing *Subscribe* is told to link and nothing is written
(kills "acts as the installer"); the interactivity dispatch table has no state verb (kills a
fact written from chat); a person linked in Teams and Slack gets one digest in a 15-minute
window (kills a per-provider budget). **Acceptance:** `go test
./control-plane/internal/hub/chat/... -race -count=1` prints `ok`; the route and matrix rows pass
with `-tags integration`. It does **not** claim: that Slack can reach the Hub through phase 8's
