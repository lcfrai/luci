# Conversation-owned reviewed task continuation

This checkpoint adds a functioning source UI for the typed coordinator continuation APIs. It is **not** a full autonomous-delivery, browser/native, Docker/provider, microVM, accessibility, latency or release acceptance result.

The primary conversation appears before its supporting policy/team/continuation controls. Continued work reads the current person's project-scoped records; it displays action state and links the exact build. An explicit implementation-policy acknowledgement enables reviewed task continuation, separately from context draft policy, provider credentials and deployment authority. The existing SessionPicker supplies the upstream route. Current saved definition/design approvals, current plan base, unfinished task selection, main checkout, authority and draft blockers remain checked, with authoritative server validation at every effect. The configured concurrency is bounded by selected tasks and the shared 200-task product limit, not a new four-task ceiling.

Before a create/advance/policy mutation, a bounded browser recovery record is stored under account/workspace/project scope. Lost responses, authority churn and scope changes retain that request; refresh reads authoritative state without re-POST. Exact nonsecret request ID, actor/project/origin/context/policy bind create readback. Client-generated HTTP-like409 remains uncertain. A parsed refusal requires subsequent readback. Same-origin retained work cannot be silently started again. Ordinary source changes can reach the server's canonical context guard instead of permanently disabling continuation in the client.

Queued tasks are never displayed as completed work. Optional independently verified check evidence remains separate from preview/release/deployment. Read denial hides cached private work. Shared policy changes invalidate the adjacent policy view and its old consent. The reused picker has explicit allocating-progress and uncertain-response copy; its default preparation/session behavior is preserved.
