# Checked-source local preview continuation

The saved project policy explicitly delegates a local preview of the exact independently checked and reviewed integrated source. The durable continuation reserves its exact release ID before the existing admitted preview handler runs. Restart and lost responses observe that identity without rebuilding or adopting another release. Current actor, Deploy permission, policy, source, requirement coverage and private configuration remain mandatory. Public publication is not authorized by this preview plan.

The fixed selected runs recorded 60 passing outcomes (59 distinct test identities across invocations), no failures and no skips. See [summary.json](summary.json), [source pins](source-sha256.json) and the [lock repair](lock-repair.diff). Shared invocation, stdout/stderr, resource observations and complete before/after source manifests are stored once in [the retention capsule](../../cloud086-shared-intents/retention/): `race-final-1` preserves the original outer timeout, `preview-first-fixed-1` the repaired first case, and `preview-rest-fixed-1` the remaining selected race checks. The original timeout produced no Go stack; recursive locking was diagnosed from source. The earlier disk-full source repair is documented separately in the summary.

Meaningful boundaries include real native Git review/integration and command outcomes, exact coverage, durable preview reservation before effects, checked-source background continuation without a browser, unchanged read-only GETs, retained running receipt recovery after restart, missing receipt/no replay, current configuration/source/Deploy/policy drift, cancellation, foreign ownership, failed HTTP health, and the ordinary direct preview path. Passing local preview health for a publish-intent run does not join a public release or assert full application behavior acceptance. Reviewed committed source from a failed/review-required worker remains eligible for independent checks after authoritative integration.

Preview execution uses a controlled typed runtime. Live Docker/provider/microVM/Windows/public deployment and product acceptance remain unverified. Automatic semantic source review, authorized Git publication and actual target deployment remain separate work; the root's full product contract is not closed here.
