### Orchestrator, swarms and microVMs

The owner's intended orchestrator-led swarms are **not shipped**. Historical
Panacea architecture described a per-user Orchestrator and sub-agents; current
Luci supports multiple real agent sessions and reviewed inputs, but does not yet
integrate autonomous swarm creation/coordination. The current project-run
contract is a record/evidence coordinator, explicitly not an autonomous executor.
Reconcile and implement the intended swarm architecture rather than relabelling
that narrower contract as a complete orchestrator.

Supported execution is **Docker locally or on the selected SSH cloud workspace**.
The retained Kata microVM backend is dormant: ordinary session requests supply
host mounts/workdir that it rejects, so the current creation path cannot run it.
Portable microVM provisioning and hosting across supported infrastructure remain
implementation/design work; neither a working microVM product nor universal
hosting portability is established.
